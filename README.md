# Foam Wars: Ev

3+1 bir evde, elinde köpük dart tabancasıyla dolaşan bir çocuğu oynadığın birinci şahıs prototip (Three.js + Electron).

## Çalıştırma

```bash
npm install
npm run desktop   # masaüstü uygulaması (NVIDIA/yüksek performans GPU zorunlu)
npm run dev       # tarayıcıda geliştirme: http://localhost:5199
npm run package   # Windows .exe → release/FoamWars-win32-x64/
```

## Kontroller

`WASD` yürü · `Shift` koş · `Space` zıpla · `C` çömel · `Sol tık` ateş · `Sağ tık` nişan · `R` şarjör · `E` dart topla · `T` hedefleri sıfırla · `L` lambalar · `F2` kalite · `F11` tam ekran

## Varlıklar

Doku, model ve HDRI'lar [Poly Haven](https://polyhaven.com)'dan (CC0). Yeniden indirmek için: `cd scripts && npm i && npm run fetch`.
